Luv Diag 0.1.0 — диагностика Amazfit Bip Max для проекта «циферблат + синхронизация». Ничего не синхронизирует:
проверяет, какие возможности часов вообще работают, чтобы потом построить настоящую синхронизацию только из рабочего.

КАК УСТАНОВИТЬ: как обычно — НОВЫЙ репозиторий, всё из папки, .github/workflows/build.yml из файла build.yml,
Settings -> Pages (ветка gh-pages), QR-код "square-432x514" в Zepp -> Режим разработчика. Парный проект: Luv Diag Face (DiagFace-v1.zip).

КАК ПОЛЬЗОВАТЬСЯ (по порядку, после каждого шага меню покажет итог):
 1 Устройство — что за часы, какие общие функции системы есть (в том числе разрешение на фоновую службу).
 2 Запись      — пишет в общую память двумя способами (ShareTypedStorage / ShareLocalStorage) и читает обратно. Это то, что не работало.
 3 Чтение      — читает записанное через TypedStorage / LocalStorage; заодно смотрит, нет ли данных от Luv Sync, «Таймера» и тестового
                 циферблата. Запускать ПОСЛЕ проверки 2.
 4 Файлы       — запись/чтение файла и проверка старых «SysPro» (hmFS).
 5 Служба      — две пробные фоновые службы. Нажмите «Старт: файл» (часы могут спросить разрешение — разрешите), потом «Старт: общая».
                 Затем ПОГАСИТЕ экран часов минуты на 2 (записи файлов из службы работают только при погашенном экране),
                 откройте Luv Diag -> 5 Служба -> «Обновить». «Стоп» останавливает обе.
Если пункт в меню написано «НЕ ОТКРЫЛАСЬ (пусто)» — эта страница не загрузилась вообще (чёрный экран): значит, какого-то модуля
на часах нет. Это тоже ценный результат, вернитесь в меню свайпом назад.

ЧТО ПРИСЛАТЬ: фото (или текст) экрана меню, затем каждой страницы 1–5. Потом — экран тестового циферблата Luv Diag Face.
